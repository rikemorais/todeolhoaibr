Núcleo do Tô De Olho Aí: abstrações de domínio e execução de DAGs.

Este crate não conhece nenhuma API pública nem tecnologia de infraestrutura. As demais camadas dependem dele, nunca o contrário (ver docs/adr/0002).

Modules§

contexto
O contexto compartilhado por todas as tarefas de uma execução: identidade e as portas de saída que elas usam para falar com o mundo externo.
dag
A DAG de uma fonte: constrói, valida e consulta o grafo de tarefas. É o único ponto do projeto que conhece a biblioteca Dagron (ver docs/adr/0003).
decisao
Pré-checagem idempotente: decide, antes de buscar, se um recurso precisa ser (re)ingerido ou se o que já está na camada Raw serve (ver issue #13).
erros
Tipos de erro do núcleo, compartilhados pelas tarefas, pelo executor e pelos adaptadores de infraestrutura que implementam as portas.
espaco
Quanto uma ingestão vai ocupar e se isso cabe no disco (ver docs/adr/0010).
estado_raw
Monta o EstadoNaRaw de um recurso: localiza o manifesto vigente pelo ponteiro _ultima_versao.json, confere completude e integridade das partes.
executor
O executor que roda a DAG de uma fonte nível a nível, com concorrência limitada, e avisa um observador sobre o início e o fim de cada tarefa.
fonte
O contrato FonteDeDados: cada API pública ingerida implementa este trait, que decide quais tarefas existem; montar e executar o grafo é igual para todas.
historico
Histórico das execuções: o que cada execução fez, publicado enquanto ela acontece. É o contrato entre a ingestão e o painel, que rodam em processos separados (ver docs/adr/0008).
portas
Portas de saída: o que o domínio precisa do mundo externo, sem saber como é feito.
raw
Contrato da camada Raw: onde os dados ficam e como cada ingestão é descrita. As futuras etapas de transformação vão ler a partir deste contrato (ver docs/adr/0006).
selecao
Escolha do que ingerir: qualquer fonte que etiquete suas tarefas pode ser filtrada, sem código específico (ver docs/adr/0010).
tarefa
A unidade de trabalho da ingestão: o trait Tarefa, o ResumoDaTarefa que ela devolve e a TarefaPlanejada que a posiciona no grafo.
