Recuperação de partes Raw órfãs: objetos gravados durante ingestões que não concluíram (erro ambíguo no manifesto, cancelamento abrupto, ou rollback incompleto). A limpeza só remove objetos comprovadamente desprotegidos — sem manifesto — e nunca atinge partes de ingestões vigentes.

Ver issue #269 e PR #278 (revisão).
