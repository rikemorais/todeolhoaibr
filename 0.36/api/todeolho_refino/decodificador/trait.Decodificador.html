Expand description

Traduz os bytes de um part do raw em uma ou mais partes de bronze (Parquet).

Um recurso de API costuma render uma parte; um ZIP com vários CSVs rende uma por CSV.

Required Methods§

Source

fn decodificar( &self, bytes: &[u8], tipo_de_conteudo: &str, ) -> Result<Vec<ParteBronze>, ErroDeRefino>

Decodifica os bytes de um part do raw, usando o tipo_de_conteudo registrado no manifesto quando precisar distinguir formatos.

Provided Methods§

Source

fn versao_regra(&self, _fonte: &str, _recurso: &str) -> Option<&'static str>

Versão adicional da regra para um recurso específico. Quando presente, entra no validador do bronze e força uma nova materialização mesmo se a Raw não mudou.

Source

fn decodificar_arquivo( &self, caminho: &Path, tipo_de_conteudo: &str, ) -> Result<Vec<ParteBronze>, ErroDeRefino>

Decodifica um part já baixado para um arquivo (sem carregá-lo inteiro na memória). O padrão lê o arquivo e chama Self::decodificar; decodificadores de arquivos grandes (ZIP em fluxo) sobrescrevem para ler direto do disco.

Source

fn decodificar_arquivos( &self, caminhos: &[PathBuf], tipo_de_conteudo: &str, ) -> Result<Vec<ParteBronze>, ErroDeRefino>

Decodifica todas as partes de um recurso de uma vez. O padrão decodifica cada arquivo em separado (uma parte Parquet por arquivo); fontes com milhares de arquivos pequenos (ex.: um processo por arquivo) sobrescrevem para agregar tudo em poucas partes.
