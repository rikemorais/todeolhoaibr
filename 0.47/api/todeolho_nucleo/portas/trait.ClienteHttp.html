fn baixar_a_partir_de<'life0, 'life1, 'life2, 'async_trait>( &'life0 self, url: &'life1 str, inicio: u64, versao: Option<&'life2 str>, ) -> Pin<Box<dyn Future<Output = Result<DownloadHttp, ErroDeIngestao>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait, 'life2: 'async_trait,

Baixa a partir de inicio (em bytes; 0 é do começo), para retomar um download interrompido sem perder nem duplicar byte. versao é o validador (ETag) da primeira resposta: a implementação deve enviar If-Range, de modo a só retomar se o arquivo não mudou. O DownloadHttp::inicio devolvido diz onde o fluxo realmente começa — se não for igual a inicio, a origem não honrou a retomada e o chamador deve recomeçar do zero em vez de emendar.

A implementação padrão ignora inicio/versao e baixa do começo, para clientes que não suportam Range; quem retoma detecta o inicio devolvido (0) diferente do pedido e recomeça.
