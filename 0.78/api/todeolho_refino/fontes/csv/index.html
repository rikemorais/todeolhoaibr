Decodificador do bronze para fontes que gravam um CSV “solto” no raw (não zipado).

Serve, por exemplo, para as despesas do Senado (CEAPS, Latin-1, com uma linha de preâmbulo antes do cabeçalho) e para as votações da Câmara (UTF-8 com BOM). O bronze só reencoda para UTF-8 e põe em colunas — a interpretação dos campos é do silver.
