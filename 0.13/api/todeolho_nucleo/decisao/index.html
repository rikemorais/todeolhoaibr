Module decisao 

Source
Expand description

Pré-checagem idempotente: decide, antes de buscar, se um recurso precisa ser (re)ingerido ou se o que já está na camada Raw serve (ver issue #13).

Esta é a regra pura, sem I/O: recebe o que a origem informou (sem baixar, via ClienteHttp::informacoes) e o estado do recurso na Raw, e devolve a decisão. Ler o manifesto e verificar integridade fica a cargo de quem monta o EstadoNaRaw.
