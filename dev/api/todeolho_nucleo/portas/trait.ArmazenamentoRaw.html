Baixa o objeto escrevendo-o em escrita, sem carregar tudo na memória; devolve false se não existir. Útil para objetos grandes (ex.: ZIPs de vários GB do TSE). O padrão usa Self::ler (carrega na memória); a infraestrutura deve transmitir em fluxo.

fn tamanho<'life0, 'life1, 'async_trait>( &'life0 self, chave: &'life1 str, ) -> Pin<Box<dyn Future<Output = Result<Option<u64>, ErroDeIngestao>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait,

Tamanho do objeto em bytes, sem baixá-lo (um HEAD), ou None se não existir. A implementação padrão lê o objeto; as de infraestrutura devem sobrescrever com um HEAD para não carregar arquivos grandes na memória.
