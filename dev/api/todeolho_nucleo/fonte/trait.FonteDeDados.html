Expand description

Uma API pública ingerida pelo projeto (o “criador” do Factory Method).

Cada fonte concreta só decide quais tarefas existem, em criar_tarefas. Validar o grafo e executá-lo é igual para todas, então novas fontes entram sem alterar o executor. Ver docs/adr/0004.
