Crate todeolho_refino 

Source
Expand description

Refino do Tô De Olho Aí: decodifica a Raw opaca para o medalhão (ver ADR 0014/0015).

A camada bronze pega os bytes fiéis da Raw e só os decodifica e estrutura em Parquet, mantendo correspondência 1:1 com a origem, sem regra de negócio (isso é silver). Este crate guarda o conhecimento de formato que o ADR 0014 mantém fora da ingestão.

Os decodificadores e a tarefa::TarefaDeBronze publicam o bronze. O módulo snapshot_bronze seleciona e verifica partes do manifesto vigente; o módulo linhagem lê essas partes em lotes e fornece referências de linha para os futuros contratos silver, sem alterar o conteúdo armazenado no bronze. O EscritorParquetTipado grava os lotes Arrow produzidos por esses contratos.
