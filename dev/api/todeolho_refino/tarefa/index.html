A TarefaDeBronze: lê um recurso do raw, decodifica e grava Parquet no bronze.

Implementa o trait Tarefa do núcleo, então roda no mesmo executor de DAG e aparece no mesmo painel da ingestão. Reaproveita os helpers de procedência do raw (manifesto, ponteiro) contra o bucket bronze — o layout é o mesmo, só muda o bucket.

Procedência: cada part do bronze registra, no manifesto, a tabela de origem e o validador da versão do raw (versao), para a idempotência: reexecutar só reprocessa quando o raw mudou.
