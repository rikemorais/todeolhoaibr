Expand description

Uma API pública ingerida pelo projeto (o “criador” do Factory Method).

Cada fonte concreta só decide quais tarefas existem, em criar_tarefas. Validar o grafo e executá-lo é igual para todas, então novas fontes entram sem alterar o executor. Ver docs/adr/0004.

fn tempo_sem_dados(&self) -> Option<Duration>

Tempo máximo sem receber nenhum byte antes de desistir. None usa o padrão do cliente HTTP (120 s). Fontes cujo servidor gera o arquivo sob demanda (ex.: WFS GetFeature) podem precisar de um valor maior.

Source

fn perfil_http_das_tarefas(&self, _tarefas: &[TarefaPlanejada]) -> PerfilHttp

Declara o perfil HTTP necessário pelas tarefas selecionadas.

A implementação padrão mantém o perfil único da fonte. Fontes que reúnem tarefas com requisitos HTTP diferentes podem ajustar o perfil após os filtros, por exemplo quando uma tarefa local não acessa a API autenticada.

Source
